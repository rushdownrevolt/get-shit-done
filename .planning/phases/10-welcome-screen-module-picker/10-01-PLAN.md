  <action>
    Add waitForPickerKey(moduleCount) function to navigator.cjs following the exact same pattern as the existing waitForKey() function (lines 35-77). The function:

    1. Returns a Promise resolving with { action: 'select', index: N } or { action: 'quit' }
    2. Uses readline.emitKeypressEvents(process.stdin), sets raw mode if TTY
    3. On keypress handler:
       - Parse number from key.name or str (parseInt). If num >= 1 && num <= moduleCount, resolve with { action: 'select', index: num - 1 }
       - If key.name === 'q' or key.name === 'escape' or (key.ctrl && key.name === 'c'), resolve with { action: 'quit' }
       - Ignore all other keys
    4. Cleanup function: removeListener, setRawMode(false), pause stdin -- exactly like existing waitForKey cleanup
    5. Add waitForPickerKey to module.exports

    The function signature and cleanup pattern MUST match the existing waitForKey to avoid raw mode leaks (Pitfall 4 from research).
