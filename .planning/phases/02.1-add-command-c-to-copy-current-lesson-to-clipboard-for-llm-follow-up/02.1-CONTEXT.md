# Phase 02.1: Add command 'c' to copy current lesson to clipboard - Context

**Gathered:** 2026-03-12
**Status:** Ready for planning

<domain>
## Phase Boundary

Add a 'c' keypress command to the lesson navigator that copies the current lesson content to the system clipboard in an LLM-friendly markdown format. The user's use case is pasting the lesson into an LLM to ask follow-up questions about the material.

</domain>

<decisions>
## Implementation Decisions

### Copy content scope
- Full lesson plain text with ANSI codes stripped
- Include everything: title, objective, all content sections, concept map, success criteria
- Code blocks include source file paths and line numbers (e.g. `// bin/gsd-tools.cjs:145`)
- Concept map (ASCII diagram) included
- "You'll know you've got it when:" label kept as-is

### Clipboard method
- Native OS commands via child_process: `clip` (Windows), `pbcopy` (macOS), `xclip` (Linux)
- Zero dependencies — aligns with GSD conventions
- On clipboard failure (e.g. xclip not installed): fall back to writing a temp .txt file and opening it automatically

### User feedback
- Flash message "✓ Copied to clipboard" shown briefly (~1.5 seconds), then screen redraws to normal lesson
- Navigation footer updated to show 'c' as available: `[n] Next  [p] Previous  [c] Copy  [q] Quit`

### LLM-friendly format
- Context preamble added at top (e.g. "This is a lesson from GSD Learn about [topic]...")
- Code blocks wrapped in markdown fences (```javascript)
- Sections structured with markdown headings (## Objective, ## Code, etc.)
- Copy lesson as-is — no prompt for user question (user types their own question in LLM after pasting)

### Claude's Discretion
- Exact preamble wording
- Flash message duration and styling
- Temp file location and naming on clipboard fallback
- How to detect which OS clipboard command to use

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `renderer.cjs:renderLesson()`: Pure function that returns ANSI-styled string — can build a parallel plain-text renderer or strip ANSI from its output
- `terminal.cjs:oscLink()`, `renderCodeBlock()`: Already handle source metadata — reuse for file:line references in plain text
- `terminal.cjs:style()`: ANSI styling function — need to strip these codes for clipboard version

### Established Patterns
- Navigator uses single-key keypresses (`n`, `p`, `q`) via readline keypress events — 'c' follows same pattern
- `waitForKey()` in navigator.cjs resolves promises on keypress — add 'c' handler here
- Renderer is pure function returning string — clipboard formatter can follow same pattern

### Integration Points
- `navigator.cjs:waitForKey()` — add 'c' key handler
- `navigator.cjs:runNavigationLoop()` — handle 'copy' action (flash message, re-render)
- `renderer.cjs` — navigation footer needs 'c' added
- New: clipboard utility module for OS-specific copy logic

</code_context>
