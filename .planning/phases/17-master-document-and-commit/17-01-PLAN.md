  <action>
In learn/lib/markdown-renderer.cjs, add a new exported function `renderReadme(modules)` that:

1. Accepts the same modules array the export script already builds: `[{ mod, lessons, spec, hints, conceptMapText }, ...]` (already sorted by order).

2. Generates a master document with this structure:
   - Title: `# GSD Curriculum: Complete AI Learning Guide`
   - Brief intro paragraph: "This document contains the complete GSD (Get Shit Done) curriculum. It is designed to be read sequentially — each module builds on the previous. By the end, you will understand how GSD commands work, how they execute end-to-end, and how GSD manages planning state."
   - A "## Table of Contents" section with nested links:
     - For each module: `- [Module N: {title}](#{anchor})` where anchor is the GitHub-style lowercase-hyphenated heading anchor
     - Under each module: indented lesson links `  - [Lesson {N}: {title}](#{anchor})`
     - Under each module: indented mini-project link `  - [Mini-Project: {spec.title}](#{anchor})`
   - A horizontal rule `---`
   - For each module: call `renderModule(mod, lessons, spec, hints, conceptMapText)` BUT bump all heading levels by 1 (# becomes ##, ## becomes ###, etc.) so the README's # title remains the only h1. Do the heading bump with a simple regex replace on the rendered output: `/^(#+)/gm` -> add one `#`.
   - Between modules: add a horizontal rule `---` separator.

3. Returns the complete markdown string.

Key implementation details:
- The heading-level bump regex: `renderedModule.replace(/^(#+)/gm, '#$1')` — prepends one # to every line starting with #.
- TOC anchors must match GitHub anchor format: lowercase, spaces to hyphens, strip special chars. For example "Lesson 1: The Two-Layer Architecture" becomes `#lesson-1-the-two-layer-architecture`. Write a small `toAnchor(text)` helper: `text.toLowerCase().replace(/[^a-z0-9 -]/g, '').replace(/\s+/g, '-')`.
- Since modules are already sorted by order in the export script, renderReadme just iterates in array order.

In learn/bin/export-docs.cjs:
- Add `renderReadme` to the require destructure from markdown-renderer.cjs
- After the existing per-module write loop, add: `const readme = renderReadme(modules); fs.writeFileSync(path.join(OUTPUT_DIR, 'README.md'), readme, 'utf-8');`
- Update the console.log to mention README: `` `Exported ${modules.length} modules + README.md to docs/ai-curriculum/` ``

Export renderReadme from the module.exports in markdown-renderer.cjs.
