  <files>learn/lib/navigator.cjs, learn/bin/gsd-learn.cjs, learn/tests/navigator.test.cjs</files>
  <action>
    **navigator.cjs changes:**

    1. Update `waitForKey()` return type to include 'skip' action. New key mappings:
       - key.name === 'w' -> resolve('next')
       - key.name === 'q' -> resolve('prev')
       - key.name === 'e' -> resolve('skip')
       - key.name === 'c' && !key.ctrl -> resolve('copy')
       - key.name === 'escape' -> resolve('quit')
       - key.ctrl && key.name === 'c' -> resolve('quit')
       - REMOVE: key.name === 'n', key.name === 'right', key.name === 'p', key.name === 'left' (arrow keys and old n/p removed entirely)

    2. Refactor `runNavigationLoop(lessons, startIndex, renderFn, progressFn, opts)`:
       - Add `opts` parameter: `{ moduleMeta, completionBannerFn }` where moduleMeta is `{title, lessonCount}` and completionBannerFn is the renderCompletionBanner function.
       - Outer loop: iterate over lessons (current lesson index).
       - Inner loop: iterate over parts within current lesson.
       - Compute totalParts per lesson: `lesson.content.length + (lesson.conceptMap ? 1 : 0)`.
       - Start each lesson at part 0.
       - renderFn signature changes to: `renderFn(lesson, partIndex, totalParts, currentLessonIndex, totalLessons)` -- matches renderPart signature.
       - Action handling in inner loop:
         - 'next': if currentPart < totalParts - 1, advance part. Else if not last lesson, advance to next lesson (part 0), call progressFn(nextLessonIndex), break inner loop. Else (last part of last lesson): show completion banner via completionBannerFn, then call waitForKey() once more (any key quits), call progressFn, return.
         - 'prev': if currentPart > 0, go back one part. If currentPart === 0, do nothing (stay on first part per user decision).
         - 'skip': if not last lesson, advance to next lesson (part 0), call progressFn(nextLessonIndex), break inner loop. If last lesson, do nothing.
         - 'copy': copy full lesson to clipboard (same logic as current -- use formatLessonForClipboard with full lesson, not just current part). Show feedback message, wait 1500ms, continue inner loop.
         - 'quit': call progressFn(currentLessonIndex), return (exits both loops).

    3. Compute totalParts across all lessons for completion banner: `lessons.reduce((sum, l) => sum + l.content.length + (l.conceptMap ? 1 : 0), 0)`.

    4. Count mini-projects: `lessons.filter(l => l.content.some(s => s.type === 'project')).length`.

    **gsd-learn.cjs changes:**

    1. Import renderPart and renderCompletionBanner from renderer.cjs (alongside or replacing renderLesson import for display purposes).
    2. Update renderFn to call renderPart: `(lesson, partIndex, totalParts, currentLessonIdx, totalLessons) => process.stdout.write(renderPart(lesson, partIndex, totalParts, currentLessonIdx, totalLessons))`.
    3. Pass opts to runNavigationLoop: `{ moduleMeta: { title: mod.title, lessonCount: mod.lessons.length }, completionBannerFn: renderCompletionBanner }`.
    4. Keep renderLesson import if other code paths use it (e.g., not used directly anymore for display, but clipboard-formatter uses its own rendering).

    **navigator.test.cjs changes:**

    Update tests:
    - Verify waitForKey is still exported as a function.
    - Verify runNavigationLoop is still exported as a function.
    - Verify setupCleanExit still callable without error.
    - Document in test comments: "Key mappings: w=next, q=prev, e=skip, c=copy, esc/Ctrl+C=quit. Arrow keys removed."
