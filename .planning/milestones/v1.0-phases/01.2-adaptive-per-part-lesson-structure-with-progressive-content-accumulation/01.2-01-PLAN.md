    2. Refactor `renderPart()` to use progressive accumulation. Keep the SAME function signature. Replace the single-block rendering (lines 188-204 current) with an accumulation loop:
       - Loop from `i = 0` to `i <= partIndex` (inclusive)
       - For each block `i`:
         - Check if it is the concept map part (`lesson.conceptMap && i === lesson.content.length`)
         - If concept map: render with hardcoded focus "Architecture Overview", no bridge
         - If content block:
           - Render focus line: current block (i === partIndex) gets `style('\u25B6 ', 'cyan') + style(section.focus, 'dim')`, prior blocks get `style('  ' + section.focus, 'dim')`
           - Render content via existing `renderContentSection(section, parts)`
           - Render bridge: always show `renderBridgeSection(section.bridge)` for the current block and for prior blocks (bridge provides context about what came next)
         - If `i < partIndex`: add dim horizontal rule separator between blocks (`horizontalRule(60)` + newlines)

    3. Remove the `getBlockHeader()` function from the module (replaced by focus field). Remove it from internal usage but keep it out of exports (it was never exported).

    4. Keep objective on partIndex === 0 only. Keep success criteria on last part only. These are UNCHANGED from current code.

    5. Keep `renderLesson` function unchanged -- it does not use focus/bridge (it renders all content at once for the legacy full-lesson view).

    **lessons.cjs changes:**

       for (let i = 0; i < lesson.content.length; i++) {

       }
