  <name>Task 1: Build export-docs.cjs script</name>
  <files>learn/bin/export-docs.cjs</files>
  <action>
    Create the export orchestration script at learn/bin/export-docs.cjs. Zero external dependencies -- only Node.js builtins (fs, path) and the renderer from Plan 01.

    The script must:
    1. Determine paths: CONTENT_DIR = path.join(__dirname, '..', 'content', 'modules'), OUTPUT_DIR = path.join(__dirname, '..', '..', 'docs', 'ai-curriculum') (relative to script location so it works from any cwd)
    2. Create OUTPUT_DIR if it does not exist (fs.mkdirSync with recursive: true)
    3. Read all module directories from CONTENT_DIR (fs.readdirSync, filter to directories that contain module.json)
    4. For each module directory:
       a. Read and parse module.json
       b. Read all lesson JSON files from lessons/ subdirectory, parse each, sort by lessonNumber
       c. Read and parse project/spec.json
       d. Read and parse project/hints.json (array of strings)
       e. Read concept-map.txt as plain text (fs.readFileSync with 'utf-8')
       f. Call renderModule(module, sortedLessons, spec, hints, conceptMapText)
       g. Write result to docs/ai-curriculum/{moduleId}.md
    5. Sort modules by module.order before processing (so output order is deterministic)
    6. Print summary to stdout: "Exported {N} modules to docs/ai-curriculum/"
    7. Add shebang line: #!/usr/bin/env node and 'use strict'

    Idempotency: The script overwrites existing files. Since renderModule is a pure function of the JSON input, running on unchanged JSON always produces identical output.

    Error handling: If a module directory is missing expected files (no lessons/, no project/), log a warning and skip that module rather than crashing.
  </action>
